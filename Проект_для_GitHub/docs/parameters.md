# Параметры реализации

| Параметр | Значение | Основание |
|---|---|---|
| Микросервисы | 5 | Требование задания |
| Ключ AES-GCM | 256 бит | Допустимый размер API AESGCM, выбран разработчиком |
| Nonce | 96 бит | Рекомендуемый размер для GCM, уникальная пара ключ/nonce |
| Тег | 128 бит | API AESGCM добавляет 16 байт к шифротексту |
| Соль пароля | 16 случайных байт | Выбор реализации, отдельная для записи |
| PBKDF2-HMAC-SHA256 | 600000 итераций | Начальная настройка стенда; не результат измерения и не заявленная норма ФСТЭК |
| Размер файла | не более 10 МиБ | Ограничение буферизации прототипа, задано MAX_FILE |
| HTTP-тело | не более 15 МиБ | Резерв для Base64 и JSON поверх файла |
| Тайм-аут межсервисного HTTP | 15 с | Начальная настройка ожидания зависимости |
| Процесс / реплика сервиса | 1 / 1 | SQLite и локальные блокировки WebDAV |
| Одновременные соединения контейнера | до 8 по настройке Uvicorn | Ограничение стенда, не пропускная способность |
| CPU request / limit | 100m / 1 | Начальные ограничения Kubernetes; нужны нагрузочные измерения |
| RAM request | 128 МиБ | Начальное резервирование, не измеренный минимум |
| RAM limit | 512 МиБ; security-crypto 768 МиБ | Запас для буферов файла и JSON; требует проверки под нагрузкой |
| PVC | 1 ГиБ на сервис | Начальная ёмкость функционального стенда |
| RSA тестового CA | 2048 бит | Конфигурация лабораторных сертификатов |
| Срок тестовых сертификатов | 365 дней | Параметр bootstrap; эксплуатационная PKI не реализована |
| Внутренний HTTPS-порт | 8443 | Выбор свободного непривилегированного порта |
| Prometheus scrape interval | 15 с | Начальный интервал наблюдения |

Версии Python и библиотек фиксируются файлами зависимостей. Теги инфраструктурных образов фиксируют выбранную ветку, но не digest; перед воспроизводимым кластерным испытанием надо записать digest реально полученных образов. Сравнительные показатели безопасности и производительности здесь не приводятся.
