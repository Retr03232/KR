# Первичные технические источники

Дата обращения: 01.11.2026. Эти источники относятся к согласованному исключению для технической документации без EDN. Научный список из первых глав они не заменяют.

25. Python Cryptographic Authority. Authenticated encryption. https://cryptography.io/en/latest/hazmat/primitives/aead/

24. Kubernetes Authors. Network Policies. https://kubernetes.io/docs/concepts/services-networking/network-policies/

28. Docker Inc. Networking in Compose. https://docs.docker.com/compose/how-tos/networking/

32. Nextcloud. WebDAV external storage. https://docs.nextcloud.com/server/stable/admin_manual/configuration_files/external_storage/webdav.html

33. Nextcloud. External Storage authentication mechanisms. https://docs.nextcloud.com/server/stable/admin_manual/configuration_files/external_storage/auth_mechanisms.html

34. FastAPI. FastAPI in Containers. https://fastapi.tiangolo.com/deployment/docker/

35. WsgiDAV. Исходный код и описание расширяемого WebDAV-сервера. https://github.com/mar10/wsgidav

36. GitHub. Building and testing Python. https://docs.github.com/en/actions/tutorials/build-and-test-code/python

37. GitLab. CI/CD YAML syntax reference. https://docs.gitlab.com/ci/yaml/

38. Nextcloud. Server-side Encryption. https://docs.nextcloud.com/server/stable/admin_manual/configuration_files/encryption_configuration.html

Номера 24, 25, 28 соответствуют существующему списку; 32–38 — предлагаемые дополнения при объединении главы. Исходный код WsgiDAV 4.4.0 дополнительно изучен в установленном пакете: dav_provider.py, http_authenticator.py, request_server.py.
